# Milk & Bananas 1.6.2

Siri and Shortcuts now advertise Add item and Search catalog. Settings includes
Apple's Siri tip and a direct link to the app's actions in Shortcuts. The redundant
Open grocery list action is removed from the icon menu and advertised shortcuts;
existing saved shortcuts can still call its intent.

Say “Add an item in Milk and Bananas” to be asked for a name. Saved catalog items
also support phrases such as “Add milk to Milk and Bananas”. Generic requests
without the app name are not registered phrases. Unknown names use the prompted
flow, which offers an explicit in-app creation step; saving remains your choice.

Catalog suggestions refresh after launch, activation, Home changes, and committed
catalog changes. Saved selections resolve their current name and reject conflicting
text or a different Home. Suggestions no longer stop after fifty catalog items.

This patch repairs the existing Siri capability. iPhone and Watch versions are
aligned at 1.6.2; the data model, CloudKit schema and entitlements are unchanged.
SHOPPING-240 records independent review, system Shortcuts evidence, tests, CI and
release processing. Simulator Shortcuts execution does not establish physical
Siri speech recognition; that remains a separate device acceptance boundary.

Local validation passed 801/801 ShoppingFast tests with no failures or skips,
plus the icon-menu/editor selection and the expanded native Shortcuts handoff
workflow on iPhone 16 Pro / iOS 27. Independent adversarial review found and
verified the fix for an exact-name collision with a different selected entity.
